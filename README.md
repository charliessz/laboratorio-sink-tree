# Laboratorio: Optimalidad y Sink Tree

Aplicación en Streamlit para analizar rutas óptimas y el Sink Tree hacia el router B.

## Tecnologías

- Python
- Streamlit
- NetworkX
- Pandas
- Plotly

## Ejecución local

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

La aplicación se abrirá en:

http://localhost:8501
